# Guide utilisateur de CalmDown

## Présentation

CalmDown est une application web de productivité qui regroupe plusieurs outils permettant d'organiser son travail, de planifier ses activités et de favoriser la concentration.

## 1. Timer Pomodoro

Le Timer Pomodoro permet d'alterner des périodes de travail et des périodes de pause.

### Utilisation

1. Choisir le mode souhaité.
2. Définir ou conserver la durée proposée.
3. Lancer le minuteur avec le bouton de démarrage.
4. Utiliser les commandes disponibles pour mettre en pause, réinitialiser ou modifier la session.

L'objectif est de travailler pendant une période déterminée puis de prendre une pause avant de reprendre.

## 2. To-Do List

La To-Do List permet de gérer les tâches quotidiennes.

### Utilisation

1. Ajouter une nouvelle tâche.
2. Consulter la liste des tâches.
3. Marquer une tâche comme terminée lorsqu'elle est réalisée.
4. Supprimer une tâche si elle n'est plus nécessaire.

## 3. Planificateur

Le planificateur permet d'organiser les activités selon les priorités et l'emploi du temps.

Il peut être utilisé pour préparer les différentes activités de la journée et mieux répartir le temps disponible.

## 4. Notes

La fonctionnalité Notes permet de conserver des informations, idées ou rappels utiles pendant l'utilisation de l'application.

## 5. Mode sombre

Le mode sombre permet de modifier l'apparence de l'interface afin d'obtenir une présentation adaptée à une utilisation dans des conditions de faible luminosité.

## Conseils d'utilisation

- Définir ses priorités avant de commencer sa journée.
- Découper les tâches importantes en plusieurs étapes.
- Utiliser le Timer Pomodoro pour structurer les périodes de concentration.
- Prévoir des pauses régulières.
- Utiliser les notes pour conserver les informations importantes.
- Faire le bilan des tâches accomplies en fin de journée.

## Résumé

CalmDown regroupe plusieurs outils complémentaires :

| Outil | Utilité |
|---|---|
| Timer Pomodoro | Structurer les périodes de travail et de pause |
| To-Do List | Gérer les tâches |
| Planificateur | Organiser les activités |
| Notes | Conserver des informations |
| Mode sombre | Adapter l'apparence de l'interface |
