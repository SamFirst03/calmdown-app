# CalmDown — Studio Focus & Productivité

Application web de productivité : timer Pomodoro, To-Do, planificateur, notes.

## Lancer en local
Ouvrir `index.html` dans un navigateur.

## Lancer avec Docker
```bash
docker build -t calmdown:v1 .
docker run -d -p 8080:80 calmdown:v1
Fonctionnalités de CalmDown

CalmDown est une application web de productivité conçue pour aider les utilisateurs à mieux organiser leur temps et leurs tâches quotidiennes.

1. Timer Pomodoro

Permet de structurer les périodes de travail et les pauses afin de favoriser la concentration.

2. Liste de tâches (To-Do List)

Permet d’organiser les tâches à réaliser et de suivre leur avancement.

3. Planificateur

Permet de planifier les activités et de mieux répartir son temps.

4. Notes

Permet de conserver des idées, des informations et des rappels utiles.

Objectif du projet

Centraliser les outils essentiels de productivité dans une interface simple et accessible depuis un navigateur web.
